# Security

## How to report a problem

Write to pavel@gurovdigital.com. Please name the version or the commit, say which file and line the problem is in, and give the steps that show it.

Please do not open a public issue for a problem that other people could misuse before a fix is released.

## Supported version

Only the latest release is supported, and fixes are released as a new version. The current version is 1.2.0, and the version number is in `plugins/duo-ready/.claude-plugin/plugin.json`.

## Security review

The review of version 1.2.0 is in [SECURITY-REVIEW.md](SECURITY-REVIEW.md). It lists what was checked, what was found, what was fixed and what the review did not cover.
